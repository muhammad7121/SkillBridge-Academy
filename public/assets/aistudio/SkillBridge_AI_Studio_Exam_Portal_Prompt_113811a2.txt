REMOTE EXAM REQUIREMENTS (important)
- Fully browser-based so remote students need only a link
- Mobile-friendly layout
- Stable on slow connections where possible
- Clear instructions before the timer starts
- Visible countdown timer; auto-submit when time ends
- Confirm before final submit
- One attempt per student by default (block second attempt)
- Save answers as they go so a refresh does not wipe progress if possible
- After submit show score, pass/fail, and optional review of correct answers

EXAM RULES (defaults)
- 40 questions randomly selected from the question bank (balanced across weeks if possible)
- 60 minutes time limit
- Pass mark: 50%
- Multiple choice only (A B C D), one correct answer each
- Allow next/previous navigation within the attempt
- Shuffle question order per attempt

EXAM SCOPE
Only Weeks 1–4 Systems Administration topics:
Week 1: IT infrastructure roles, hardware, cabling, asset registers, support tickets, physical-layer troubleshooting, lab safety
Week 2: Windows 11 deployment, local accounts, least privilege, build records, controlled shares
Week 3: VirtualBox lab network 192.168.10.0/24, DC01 192.168.10.10, domain skillbridge.local, AD DS, DNS, DHCP 192.168.10.100–200, domain join, LabShare, snapshots
Week 4: Ubuntu Server lnx01 192.168.10.20, Netplan, SSH/PuTTY, apt, users/permissions, nginx, UFW, fstab, cron, snapshots

Do NOT include Weeks 5–8 pure networking exam content.
